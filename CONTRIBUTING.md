# Contributing

Everything lives in `README.md`. Add one table row to the right section (create a new `###` section under the right `##` category if none fits, and add it to the Contents list at the top). Things that run on their own and don't plug into an agent go under **Standalone**.

Category names stay short and plain (`Video`, `Marketing`). The entry itself can be as descriptive as needed.

Columns: **Name** (linked to the repo or URL) · **Type** (use one from [Types used in tables](README.md#types-used-in-tables), or combine two like `skill + CLI`) · **What it does** (one sentence, checked against the linked page). No install commands.

Don't edit **Start here** or **Recently added** in a pull request. The maintainer updates those.

Rules:

- Free or freemium only. No paid-only tools or MCP servers. Optional paid tiers are fine if the core is free.
- No MCP servers that only connect Claude to one company's own product or account. List tools that work on their own, on your machine or on any site.
- Tools that also work with other agents are fine, as long as they clearly support Claude.
- Only list things you've used or read the README of. No paid ads, no dead links.
- Aim for repos with 500+ stars. A smaller repo is fine if it is new or niche, clearly useful and actively maintained. Say why in the pull request.
- If an entry fits two categories, put it in the main one and add a cross-link in the other.
- Say so if it sends emails, runs code or spends money.
